## 腾讯云轻量 SSH 认证排查（43.142.156.50）
- 用户 `scp ... root@43.142.156.50:/root/` 报 `Permission denied (publickey)`。
- 结论（ssh -v 证据）：服务器只提供 `publickey` 认证；**`ubuntu` 用户认可** `~/.ssh/tencent_lighthouse_ed25519`（`Server accepts key ... SHA256:jmBLFHG0vhC4/Icv4Clw87cAMnmvFVwVJigye2u6l+E`，与本地 .pub 指纹一致），**`root` 完全不接受**。`id_ed25519` 也不被接受。
- 该私钥是 **bcrypt 加密带 passphrase**（`ssh-keygen -y -P ""` 失败，OpenSSH 私钥头含 bcrypt），所以 BatchMode 探测一律失败属正常；交互执行会提示 `Enter passphrase for key`，输入创建密钥时的口令即可。
- 正确命令：`scp -o IdentitiesOnly=yes -i "$env:USERPROFILE\.ssh\tencent_lighthouse_ed25519" <包> ubuntu@43.142.156.50:/home/ubuntu/`（注意目标目录是 `/home/ubuntu/`，不是 `/root/`）。
- 据此已更新 `deploy/server-init.sh`：支持 `PUBLIC_IP` 环境变量显式指定公网 IP；普通用户不在 docker 组时自动对 compose 加 sudo；Docker 安装优先 Ubuntu 源 `docker.io docker-compose-v2`（国内快），失败再退回 get.docker.com；`bash -n` 通过，并在 WSL 真实跑通（容器 Healthy、首页 200）。README 上传章节与故障排查表同步更新。部署包已重新打包（99 文件 / 3.20 MB）。
