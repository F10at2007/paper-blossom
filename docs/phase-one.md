## 素材来源

四份 SVG 是本项目基于对称、镂空与几何重复原理原创编写的示意纹样。未复制外部纹样。纸感使用自主 CSS 与内联 SVG 噪声，无外部素材请求、字体下载或第三方许可依赖。

## 明确未实现

剪纸绘制、折叠映射/展开、临摹评分、纹样拖放组合、撤销重做清空、换色、放大预览、本地保存、自动保存、PNG 导出、作品编辑删除、用户账号及云端存储。所有相关按钮均只打开状态提示，不产生业务数据。

## 风险与下一阶段建议

1. 一周交付优先做好一个最小创作闭环：确定画布尺寸与坐标体系，再实现单一模式的基础操作和撤销；确认后才推进保存与导出。
2. 先约定作品数据结构（模式、版本、名称、修改时间、图形内容），然后统一接入作品管理；当前卡片示例不是数据协议。
3. 四模式需要不同的绘制与交互行为，避免直接把 SVG 示意图当作游戏算法。尤其折叠映射应独立验证。
4. 系统字体因设备变化会有差异，比赛机器需检查文字换行和 Chrome 129 的交互、缩放及布局。
5. 当前沿用开发配置；公网部署前另行处理密钥、DEBUG、域名与静态资源托管。本阶段不部署。

第一阶段结束，未开始任何真实游戏逻辑。
