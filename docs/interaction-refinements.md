# 交互修复与创作辅助验收

## 修改内容

1. 保存时比较载入记录的完整版本，阻止旧页面覆盖其他页面的新修改；作品列表重命名也使用版本检查。
2. 原记录被删除时保留当前画布，允许直接另存副本；另存会生成独立 ID，随后保存更新该副本。
3. 拼接每片素材先裁剪到自身外轮廓，再作 evenodd 镂空填充；调整团花、六角孔洞与花瓣的方向，消除外部碎片。旧作品中的这两款素材将使用修正后的外观。
4. 选择命中同时考虑外轮廓和孔洞，透明区域允许点击下层纸片；放大/缩小到极限后按钮禁用，无变化操作不增加历史。
5. 临摹完成后清空会恢复编辑状态，能够立即继续绘制。
6. 四模式共用未保存状态、离开提醒、另存副本、放大画布和快捷键。没有自动保存；刷新警告依赖浏览器的用户交互条件，不保证在进程被强制关闭等情况下出现。
7. 临摹新增独立透明 Canvas 虚线参考层，默认显示，支持开关，并随纸张等比缩放。参考轮廓不是用户剪裁数据，不进入缩略图、对比中的用户作品和 PNG。独立参考图和三幅练习仍保留。

保持 Django、原生 Canvas 和原有朱砂红/米白/墨黑样式，没有新依赖、第五种模式或后端存储。
