## 模式三：纹样临摹

三个原创参考图均以独立的几何路径定义，使用独立 Canvas 显示，用户绘制不能修改参考图：

| 图案 | 难度 | 本项目练习目标 |
| --- | --- | --- |
| 初绽 | 简单 | 六瓣轮廓与中心圆，练习留出连续纸桥 |
| 叶语 | 中等 | 成对叶片的长短与朝向，练习多次闭合剪裁 |
| 花窗 | 较复杂 | 内外圈连续纹样，练习不同大小的留白 |

这些是本项目原创练习名称，并非某个传统流派的指定纹样或历史文物复刻，不为它们编造祈福寓意。图形全部由代码自主设计，无外部图片或纹样授权依赖。

复用第二阶段 `mountWorkshop`、`CutHistory`、真实镂空与共用导出。支持参考选择/显隐、用户剪裁、独立的左右对比、完成作品和继续临摹。对比弹窗的“继续临摹”可直接恢复绘制；保存包含参考 ID、完成状态和用户路径。下载只渲染用户数据，不包含参考图。

## 模式四：百纹成画

12 个原创素材，全部可独立编辑：

| 分类 | 素材 |
| --- | --- |
| 花卉 | 花瓣、叶片、团花 |
| 动物 | 蝶影、小鸟、游鱼 |
| 几何 | 菱花、圆环、六角 |
| 边框 | 回廊、波带、折角 |

点击素材添加，点击纸片选中并拖动，点击空白/取消选择/Escape 取消选择。提供缩小、放大、左右旋转、复制、删除选中、带确认的清空，以及撤销重做。每个元素保存唯一 ID、素材 ID、中心位置、比例和角度。每幅最多 80 个元素。

每片纸以轮廓及内部镂空一次 evenodd 填充，然后叠放到透明画布。上层纸片的洞不会擦去下层纸片，元素可以独立选择和重排位置。没有高级图层、节点编辑或素材市场。

“完成并预览”显示不含选框的最终构图；下载使用共用 `paper-download.js`，仅替换最终渲染回调。2048×2048 PNG 保留透明背景，不包含素材面板或选择边框。超出画布的部分在显示与导出时采用相同边界裁剪。

## 本地作品

`localStorage` 键为 `paper-blooms.works.v1`，记录是 `{version:1, works:[...]}`。单幅记录包含 ID、名称、创建和修改时间、160×160 缩略图以及结构化 document：

- free：纸色与剪裁路径。
- fold：纸色、基础剪裁路径、折法、编辑/展开视图状态。
- trace：纸色、用户路径、参考图 ID、完成状态。
- compose：纸色与每个素材的 ID、位置、大小、旋转角度。

四模式共用手动保存/恢复接口，保存后更新当前 URL 的作品 ID，后续保存更新同一条记录，保留创建时间并更新修改时间。保存前生成最终缩略图，不存 2048 PNG。没有逐指针写入，也没有自动保存。

“我的作品”已替换旧示例布局，显示真实记录、缩略图、模式和时间。支持筛选、继续编辑、PNG、重命名、确认删除及空状态。可导出本地原始 JSON 备份，并在校验通过及确认后导入替换。导入文件只在浏览器中读取。

保护措施：最多 30 幅、总内容最多 150 万字符、单项缩略图上限、几何/模式/版本校验、路径与元素数量保护。写入是一次 setItem；容量或权限失败时保留旧记录并提示。损坏记录不会被静默清空，可导出原始备份或导入有效备份；页面和工坊入口保持可用。作品名称使用 textContent 显示，带 HTML 字符的名称不会作为标签执行。

记录仅限当前浏览器和同一 origin，不上传、不保证跨设备同步，清除站点数据后可能丢失。JSON 保存的是编辑状态，PNG 仅保存成图。自由/折纸/临摹恢复后可撤销基础剪裁路径；拼接恢复的是当前可编辑元素，不保存上次会话的完整撤销栈。

## 对现有功能的影响评估

- 未更改自由剪裁与折叠映射算法。共用绘图控制器只增加可选扩展接口与保存恢复入口。
- 自由剪艺保持实时预览、四纸色、历史与透明下载。
- 折纸保持纸片居中、纸外起笔、隐藏其他区域、仅展开后显示完整作品与启用编辑页下载。返回剪裁不丢基础路径。
- 折纸手动保存时缩略图渲染完整成图，作品列表的 PNG 始终导出完整作品；编辑页依然没有实时展开预览。
- PNG 编码、文件下载与 URL 清理为一套共用实现，临摹导出用户路径，拼接提供自己的最终场景渲染回调。
- 后端仍只负责既有页面渲染和静态资源，没有作品 API。增加 STATIC_ROOT 仅用于可复现 collectstatic，并忽略生成目录。

## 依赖与原创性

`requirements.txt` 未改：Django 6.1.2（既有页面与静态服务）、asgiref 3.12.1（Django ASGI）、sqlparse 0.6.0（Django SQL 依赖）、tzdata 2026.5（Windows 时区）。Node 与独立 Chrome 仅用于验收，不是网页运行依赖。没有预设 UI 库、绘图库、字体 CDN 或动画库。

三幅练习、十二个素材及首页 SVG 均为自主几何绘制；不复制网站、开源剪纸素材或获奖作品。文化背景仅引用 [UNESCO 中国剪纸](https://ich.unesco.org/en/RL/chinese-paper-cut-00219) 支持“中国剪纸于 2009 年列入代表作名录”及代际传承的一般介绍，不据此推导本项目素材的历史名称、地域、寓意。未下载或复用 UNESCO 图片和视频。

运行资源均在本项目中，初次加载不依赖外部图像、字体或服务。文化来源链接由用户主动点击打开，不用于加载或上传作品。

## 尚存边界与停止范围

- 触控为 Chrome 129 模拟输入，未以实体手机/平板手工验证；未做极大量长路径的性能压力测试。
- Canvas 抗锯齿在镜像边缘及不同输出分辨率下有正常的采样差异；几何映射、内部像素和接缝已测，不宣称整个位图逐像素完全一致。
- 本地存储有容量与浏览器 origin 限制，不提供跨设备同步；请使用 JSON 备份。
- 当前是本地比赛演示配置；公网部署前需要常规生产配置，不能把 Django 开发服务器当生产部署。
- 不开发 AI 评分、关卡解锁、账号、云端同步、复杂图层或第五种模式。第四阶段结束后暂停；按本次授权提交并推送后，不继续下一阶段。
