# 第三阶段：折纸成花

## 使用与完成范围

沿用 Django + Canvas 2D + 原生 JavaScript，没有新增依赖。

```powershell
.\.venv\Scripts\Activate.ps1
python manage.py runserver
```

访问 http://127.0.0.1:8000/workshop/fold/ 。选择折法，纸片居中显示；可在绘图区内的纸外起笔。松手自动闭合，只剪去轮廓与纸片相交的部分。点击“展开作品”查看全纸对称图案，点击“返回剪裁”继续编辑。切换折法有清除历史确认，“重新开始”恢复当前纸色和折法的完整纸张。

对折（含垂直/水平）、四折、八折均已实现，作品来自用户实际绘制，没有使用示例图案代替剪裁。八折采用几何扇区，不模拟物理折叠。当前交互仅在点击“展开作品”后显示完整作品并启用下载；剪裁时没有成品实时预览。PNG 输出展开后的完整纸张。

## 第二阶段复用与最小调整

- 继续使用 `CutHistory` 的 points 数组与路径/重做栈，坐标仍为 [0,1]，未重写历史系统。
- `FoldSession` 保存当前折法与 `choose / editing / unfolded` 状态，引用同一个 CutHistory。`operations` 视图将基础路径表示为 `{type:'polygon', fold, points}`。切换折法确认后重置两个历史栈，避免旧路径跨域误用。
- 同一个 `free-workshop.js` 控制器处理两个模式的鼠标、触控、中断、撤销重做、颜色和预览；fold 分支增加区域判断、路径裁剪及视图切换。保留原文件名以减少第一、二阶段文件变动。
- 同一个 `renderPaper` 从完整纸色重建，使用 `destination-out` 和 evenodd 填充生成真实透明镂空。仅增加可选剪裁组参数，默认自由剪艺行为不变。
- 把第二阶段已有的下载流程抽到 `paper-download.js`，两个模式共用 2048×2048 重绘、pngBlob、失败处理、下载链接及 URL 清理。
- 复用工作台结构、颜色选择、预览对话框与基础 CSS。折痕、遮盖及方向文字绘在独立辅助 Canvas 上，不参与作品渲染和 PNG 导出。

## 坐标与几何映射

单位正方形左上为 (0,0)，右下为 (1,1)，中心为 (.5,.5)，x 向右、y 向下。

| 折法 | 基础区域 | 展开映射 |
| --- | --- | --- |
| 垂直对折 | 0≤x≤.5，0≤y≤1 | 原图与 (1-x,y) |
| 水平对折 | 0≤x≤1，0≤y≤.5 | 原图与 (x,1-y) |
| 四折 | 0≤x≤.5，0≤y≤.5 | 原图、水平镜像、垂直镜像、双向镜像 |
| 八折 | 0≤y≤x≤.5，三角形 (0,0)、(.5,0)、(.5,.5) | 四折的四个映射，加 (y,x)、(1-y,x)、(y,1-x)、(1-y,1-x) |

八折用方形的 D4 等距变换构成八个 45° 三角区域：四次 90° 旋转及镜像的等价组合。它具有四条镜像轴与八个对应区域，并非把方形外框强行变为 45° 旋转不变的圆形作品。所有变换仅交换、反转坐标，没有拉伸或缩放。反射副本调整顶点顺序以保持一致绕向。

当前允许在整个绘图区（包括纸片之外）起笔；根据居中视图的逆变换获取原纸张坐标，临时轮廓在纸外也能看见。提交时通过 Sutherland-Hodgman 算法将封闭轮廓裁到凸多边形区域，之后才加入历史。交点浮点误差收敛到单位纸张边界，最终路径都在纸内。

### 折痕接缝处理

如果逐个擦除相邻镜像副本，斜向共享边的抗锯齿会造成半透明纸缝。因此每次基础剪裁的全部副本组成一个 compound path，只填充擦除一次，由光栅器先处理共享边；不同基础剪裁仍分别擦除，重叠操作不会互相抵消。自由剪艺仍使用单路径组。预览与导出均使用这一规则。

展开只改变视图状态，不生成新的基础剪裁操作。修改历史或换色时重新映射；返回剪裁时基础路径和折法不变。展开后的淡入仅影响显示元素 opacity，最终位图先生成且保持正确；减少动态效果设置下取消动画。

## 尚存边界

- 已实现三种折法，没有缺失的折法或预制纹样替代。
- 触控为 Chrome 129 模拟输入，尚未在实体手机/平板上手工测试；未进行极大量路径和超长手势的压力测试。
- 八折是几何简化，不模拟物理厚度与三维翻折。
- 仍无持久化；离开/刷新页面可能丢失作品。已有下载能力用于保存最终图像，不等同于可继续编辑的作品文件。
- 下一步建议先做比赛机器和实体触屏体验检查；其余模式与作品管理需另行授权，本阶段到此暂停。

## 交互调整：先剪后展开、纸片居中、纸外起笔

本节为当前行为，取代初版中的实时预览、原方形区域展示和纸外禁止落笔规则。

- 折纸模式移除侧栏实时成品预览和放大预览。剪裁时不渲染任何完整展开图；点击展开后才在主画布生成完整作品并启用下载。返回剪裁后再次禁用下载，需重新展开查看当前结果。
- 仅显示居中的实际折叠纸片，不再显示其他象限或灰色遮盖区域。居中视图按纸片包围框等比缩放，四周保留 12% 空白。这个变换仅用于显示，不改变原有剪裁与展开坐标。
- 通过 `foldView`、`toFoldView`、`fromFoldView` 在显示坐标和原纸坐标间转换；几何路径与展开算法不变。显示端只将基本纸片裁出并居中绘制，棋盘格也仅位于实际纸片范围内。
- 允许从绘图区内的纸外起笔，辅助线会完整显示；结束后将闭合轮廓裁到纸片范围内。完全在纸外、未与纸片相交的轮廓不会加入历史；跨纸边轮廓可形成边缘缺口。
- 共用控制器只对 fold 分支改变行为，自由剪艺保留实时预览和原有绘制方式。
